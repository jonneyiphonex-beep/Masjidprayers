# Masjidprayers

## تشغيل التطبيق

المشروع صفحة ويب ثابتة ولا يحتاج إلى تثبيت حزم. قبل التشغيل محليًا، أنشئ ملف بيانات المساجد (يتطلب اتصالًا بالإنترنت):

```sh
python3 .github/scripts/fetch_mosques.py
```

ثم شغّل خادمًا محليًا من مجلد المشروع:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

ثم افتح `http://localhost:3000`. يعرض التطبيق المساجد المسجلة في ولايات السودان على الخريطة والقائمة باستخدام OpenStreetMap، ويحدّث ملف البيانات تلقائيًا عند النشر ومرة أسبوعيًا. قد لا تشمل البيانات مسجدًا غير مسجل أو غير موسوم في OpenStreetMap، لذلك لا تمثل حصرًا رسميًا كاملًا. تظهر بيانات المسجد الأقرب والقبلة ومواقيت الصلاة افتراضيًا للخرطوم، ويمكن تحديد موقعك أو اختيار نقطة على الخريطة لتحديثها. تُحسب القبلة محليًا، ومواقيت الصلاة تقديرية بطريقة MWL (الفجر 18° والعشاء 17°) مع تقدير فرق التوقيت من خط الطول؛ وقد تختلف عن التوقيت الرسمي. يتطلب تحميل الخريطة والطرق اتصالًا بالإنترنت. في Codespaces، اجعل المنفذ 3000 متاحًا من تبويب **Ports**.
