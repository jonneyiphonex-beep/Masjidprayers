# Masjidprayers

## تشغيل التطبيق

المشروع صفحة ويب ثابتة ولا يحتاج إلى تثبيت حزم. شغّل خادمًا محليًا من مجلد المشروع:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

ثم افتح `http://localhost:3000`. يستخدم التطبيق خرائط OpenStreetMap وواجهات Overpass احتياطية لجلب بيانات المساجد. يحاول تحديد موقعك تلقائيًا عند الفتح؛ اسمح بإذن الموقع في المتصفح. إذا تعذر تحديده، يستخدم الموقع الافتراضي ويبيّن ذلك. يجلب بيانات المساجد المسجّلة في السودان، ويعرض أقرب مسجد مع المسافة المباشرة واتجاه البوصلة ورابط الملاحة، إضافة إلى قائمة المساجد مرتبة حسب المسافة. وتظهر علامات المساجد الواقعة ضمن نطاق الخريطة المرئي، مع تمييز المسجد الأقرب. قد يستغرق تحميل بيانات البلد وقتًا أطول، وقد تتأخر خدمات Overpass أو تُرجع خطأ ازدحام (مثل HTTP 502)؛ عندها يوضح التطبيق السبب ويتيح إعادة المحاولة يدويًا. قد لا تظهر مساجد غير مسجّلة في OpenStreetMap. المسافة والاتجاه خط مستقيم وليسا مسار شارع؛ يفتح رابط الملاحة الاتجاهات إلى المسجد في خرائط Google. تُحسب القبلة ومواقيت الصلوات الخمس محليًا دون API خارجي؛ المواقيت تقريبية بطريقة MWL (الفجر 18° والعشاء 17°) ويُقدّر فرق التوقيت من خط الطول، لذلك قد تختلف في المناطق ذات التوقيت النصفي أو التوقيت الصيفي. يتطلب تحميل الخريطة والمساجد اتصالًا بالإنترنت. في Codespaces، اجعل المنفذ 3000 متاحًا من تبويب **Ports**.
