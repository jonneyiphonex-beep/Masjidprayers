# Masjidprayers

## تشغيل التطبيق

المشروع صفحة ويب ثابتة ولا يحتاج إلى تثبيت حزم. شغّل خادمًا محليًا من مجلد المشروع:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

ثم افتح `http://localhost:3000`. يستخدم التطبيق خرائط OpenStreetMap وخدمة Photon للبحث عن المساجد قرب موقعك، ويعرض النتائج التي تعيدها الخدمة على الخريطة وفي قائمة مرتبة حسب المسافة، دون حد ثابت قدره 12 كم. قد تقتصر النتائج على عدد الخدمة المتاح لكل بحث، وقد لا تظهر مساجد غير مسجّلة في OpenStreetMap. يعرض التطبيق أقرب مسجد ومسافة الطريق، ويتيح اختيار أي مسجد من القائمة لعرضه على الخريطة. يحاول تحديد موقعك تلقائيًا عند الفتح؛ اسمح بإذن الموقع في المتصفح. إذا تعذر تحديده، يستخدم الموقع الافتراضي ويبيّن ذلك. قد تتأخر خدمة البحث أو تُرجع خطأ؛ عندها يوضح التطبيق السبب. تُحسب القبلة ومواقيت الصلوات الخمس محليًا دون API خارجي؛ المواقيت تقريبية بطريقة MWL (الفجر 18° والعشاء 17°) ويُقدّر فرق التوقيت من خط الطول، لذلك قد تختلف في المناطق ذات التوقيت النصفي أو التوقيت الصيفي. يتطلب تحميل الخريطة والمساجد اتصالًا بالإنترنت. في Codespaces، اجعل المنفذ 3000 متاحًا من تبويب **Ports**.
