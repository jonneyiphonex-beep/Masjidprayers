# Masjidprayers

## تشغيل التطبيق

المشروع صفحة ويب ثابتة ولا يحتاج إلى تثبيت حزم. شغّل خادمًا محليًا من مجلد المشروع:

```sh
python3 -m http.server 4173 --bind 0.0.0.0
```

ثم افتح `http://localhost:4173`. يحاول التطبيق تحديد موقعك تلقائيًا عند فتح الصفحة؛ اسمح بإذن الموقع في المتصفح. يمكنك إعادة المحاولة بزر «تحديد موقعي». في Codespaces، اجعل المنفذ 4173 متاحًا من تبويب **Ports**. يتطلب تحديد الموقع اتصالًا بالإنترنت للوصول إلى خدمات الخرائط ومواقيت الصلاة.
